Learning Lab - Chapter 8

How Much Do You See at Once?

In two sets of trials, a 3-by-3 grid of letters will flash briefly on screen. In the first set, try to report as many letters as you can from the whole grid. In the second set, you will not know which row to report until after the grid has already disappeared.

This is a teaching demonstration of iconic memory and the partial-report advantage, not a diagnostic test of your vision or attention.

Accessibility and Privacy

This lab requires the ability to read a briefly displayed letter grid (approximately 100 milliseconds). It runs entirely in your browser and stores your prediction, trial responses, explanation, and transfer response in sessionStorage for this browser session only. It sends no data to a server.

Predict and Commit

After a very brief flash of a 3-by-3 grid of letters, how many of the 9 letters do you predict you will be able to report?

Part 1: Whole Report

In each of three trials, a 3-by-3 grid of 9 letters will flash for about one tenth of a second. Immediately after it disappears, type as many letters as you remember from anywhere in the grid. Order does not matter.

Each grid contains nine unrelated consonants. Do not look for patterns or words — just see as many letters as you can.

What to notice

Most people correctly identify 3 to 5 letters from the whole grid — well below the 9 available. This is not because they failed to see the grid. It is because verbal encoding is slow: by the time you have named a few letters, the others have faded. Sperling asked whether those lost letters were actually there at the moment of the flash, before fading began.

Part 2: Partial Report

In each of three trials, the same kind of grid will flash for the same brief duration. This time, you will not know which row to report until after the grid has already disappeared. A cue will appear immediately telling you to report only the top, middle, or bottom row.

Because the cue comes after the flash, you cannot prepare for it in advance. You must try to see the whole grid, then retrieve only the cued row from memory.

What the activity was designed to show

Sperling (1960) found that partial-report performance, when scaled to the full grid, exceeded whole-report performance. This shows that iconic memory initially holds a richer representation than verbal report can extract — the bottleneck is not in seeing the grid but in naming letters before the sensory trace decays. Partial report bypasses the bottleneck: the post-flash cue tells the visual system which letters to retrieve before they fade, and performance on any cued row is high precisely because all rows were available.

If your estimated capacity exceeded your whole-report average, your data follow the expected direction. If they did not, that can happen with short experiments: browser rendering timing varies, partial-report strategy differs across individuals, and three trials per condition give a noisy estimate.

Do Not Confuse: Sensory Memory with Short-Term Memory

Iconic memory is a brief, high-capacity sensory buffer — not short-term memory. Its capacity is large (roughly the full visual scene), but its duration is extremely short (a fraction of a second). Short-term memory has smaller capacity but longer duration and can be sustained by rehearsal. What Sperling demonstrated is that the visual system retains a complete representation of the stimulus briefly, even though short-term memory cannot hold all nine grid letters simultaneously. The partial-report advantage is evidence of the initial sensory representation, not of improved short-term encoding.

Retrieve and Transfer

Instructor Note

Run before or after the Sperling discussion. Most students predict 5 to 7 letters and report 3 to 4 in whole-report trials — the mismatch is a good debrief anchor. Key question: why did partial-report performance, scaled up, exceed whole-report performance if the grid was flashed for the same duration? If partial performance was also low, discuss whether strategy (trying to name letters before the cue appeared) or screen rendering variability affected results. Avoid emphasizing individual scores; compare class aggregate averages.

Evidence Base

The design replicates the logic of Sperling (1960). This version uses a 100-millisecond flash (versus the range Sperling used) to accommodate browser-rendering variability across devices. Partial-report cues are delivered by text rather than tone, and the grid is 3-by-3 rather than the larger arrays in the original studies. The core logic is preserved: the row cue comes only after the flash, so participants must hold the full grid in sensory memory to perform well on any cued row.
