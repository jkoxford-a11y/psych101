## Editorial review

- **`check_chapter_coherence.py`'s citation and Key Terms checks have three more false-positive classes, found 2026-07-27 on Chapter 2 (in addition to the Connections-anchor class below).** All three verified by hand against the actual References list and body prose before being written off — no chapter content changed for any of them, per the same rule the anchor case below establishes. (1) *Reference-entry parenthetical containing more than a bare year*: `reference_keys()`'s regex requires a reference line's date parenthetical to be exactly `(YYYY)` or `(YYYYa)`; a correctly-APA-formatted webpage citation like `Centers for Disease Control and Prevention. (2024, September 4).` never matches, so its citation is reported as "no reference entry" even though the reference exists and is correctly cited in Ch. 2's Tuskegee passage. (2) *Institutional-author keying picks a different word depending on direction*: the citation-side regex keys an institutional author by the **first** word of its name in-text ("National Commission..." → `national`), while the reference-side regex keys it by the **last** word of the full author string before the year ("...Research." → `research`) — different `ORGS` buckets, so a real, correctly cited-and-listed reference (the 1979 Belmont Report) shows up as missing in both directions at once. This is the same general failure mode as the Connections-anchor case (two independent approximations of the same thing, computed differently, then compared to each other) rather than a new mechanism. (3) *Slash-joined Key Terms headings*: a term defined as `**Placebo / placebo effect** — ...` or `**Volunteer bias / sampling bias** — ...` is checked as one literal string against the body; it will essentially never match even when both halves are individually, correctly used in body prose, because nothing forces a chapter to ever write the joined form. Also noted in passing but not yet verified as a distinct class: "Author and colleagues (YEAR)" narrative citations (vs. "et al.") and multi-year combined citations like "(Author & Author2, 2001, 2010)" both under-match on the citation side, surfacing real references as "not cited" at the review level — lower priority since these are REVIEW, not FAIL, findings. Worth fixing the underlying regexes (split Key Terms on `/` and check each side; normalize institutional-author keys the same way on both sides; loosen the reference-parenthetical date regex) rather than leaving this as a second standing trap, but not blocking — Ch. 2's actual citations and Key Terms are all correct as written.
